# Si 双倾导航

轻量版和全清晰版的控制区新增“α / β 带轴导航”。所有运算在浏览器执行，无机台连接。

## 操作

1. 打开导航。输入已精对准的当前晶带轴、同带轴下的一个 Si 允许反射及 000 到该斑点的屏幕方位。
2. 输入参考 α₀、β₀。在“样品杆标定与限位”中填写真实限位、两轴符号和 α 正轴在屏幕中的方位。后者与参考斑点方位是不同参数。屏幕坐标向右为 X，向上为 Y。
3. 点击“建立参考取向”。修改参考参数后，必须重新建立，旧解即失效。
4. 输入完整目标指数或点击导航图的菊池极；球面标注的所选极也会传入目标。目标不会自动替换为晶向族中的另一个方向。
5. 点击“计算目标 α / β”，查看绝对角度、相对当前读数的增量和可达性。可以播放路径、停止、直接到达终点或手动调整滑块。
6. 用 ±35° / ±60° 导航；改为 ±2° 查看衍射位置与极点精调。关闭导航后，主球体保留当前取向。拖动主球体只改变观察视角；重新打开导航恢复按倾角计算的束向。

默认示例：参考 [110]、反射 (2 −2 0)、参考角及两种方位均为 0°；目标 [121]。本模块轴序下 α≈−24.094843°、β≈18.434949°，模拟残差为零。指定 [112] 与 [110] 相差 54.735610°，在默认 α±35°、β±30° 下不可达；不能将其误记为 30°。

## 数学约定

晶体坐标采用立方正交基。列向量，电子束为 +Z，零位 α 轴为 X，β 轴为 Y；外轴 α 固定，内轴 β 随 α 运动。

`A(a,b) = Rx(sa*a) Ry(sb*b)`

参考配准矩阵 `U0` 将晶体映射到去掉屏幕轴方位后的显微镜坐标。任意读数下：

`U(a,b) = A(a,b) inverse(A(a0,b0)) U0`

用于屏幕投影的矩阵另左乘 `Rz(axisAzimuth)`。参考图样方位使用 `spotAzimuth - axisAzimuth`，避免混淆屏幕旋转与真实样品杆旋转。

目标带轴要求 `U normalize(uvw) = [0,0,1]`；解析枚举角度分支并筛选限位，以读数增量的欧氏范数选解。目标晶面平行电子束要求 `dot(U normalize(hkl), [0,0,1]) = 0`；按 α≤0.1° 间隔采样并解析求 β，同时检查 β 边界，选较近可行解，不声称是全局最短路径。

## 范围与限制

- 本模块为 Si 几何导航。进入导航时球体切换为 FCC 图纸；图纸是立方中心线参考，不是 Si 动力学强度图。
- 默认限位是示例，未标定前不能作为机台角度指令。
- 只检查两轴角度边界，不检查载网遮挡、杆体碰撞、漂移、弯曲或同一区域保持情况。
- 衍射位置采用 200 kV、a=0.5431 nm、指数绝对值≤8、金刚石消光及径向偏离≤0.15 nm⁻¹ 的几何筛选。透明度不代表实测强度，也不是定量厚度模型。
- 菊池图为中心线；不模拟带宽、布拉格边界、动力学禁反射或双束条件。当前两种目标为晶带轴对准和晶面平行束向。
- 所有图形使用同一个取向矩阵；球体自由观察不反向修改样品杆状态。
