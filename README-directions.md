## 使用

在“任意晶向 [uvw]”输入 `112`、`[113]`、`3 3 0` 或 `-1 1 3`，点击“转到晶向”或按 Enter。

- 适用于此项目的 FCC/BCC 立方模型。整数方向约简保留正负号，[330] 与 [110] 同向。
- 支持三个安全整数；多位数和负数用空格或逗号分隔；拒绝 [000]。
- 中心圆标记对应指定观察方向；右侧仍展示整张图纸面，标签指面中心。
- 任意方向定位不增加原图未绘制的菊池线、标签或衍射强度。
- 拖动、方向键或自动旋转后回到自由视角，分享链接不再附带固定晶向。
- 轻量版与全清晰版均支持 uvw 链接参数，优先于 q 恢复晶向。

## 球面交点坐标（更新）

点击交点，直接在主模型保留红色 [uvw] 标注，可以同时选择多个交点。“显示其他交点坐标”显示自动避让的坐标层；取消勾选后，手动选中的标注仍保留。鼠标经过交点会提示其坐标。

在任意晶向输入框填入例如 `316`，点击“标注输入晶向”即可保留该交点的坐标而不旋转球体。不是当前线族交点的任意方向，仍可用“转到晶向”观察，但不当作菊池极加入。

选中后可以“沿选中极观察”“放大选中极”或“清除标注”。分享链接通过 `poles` 保存多点标注，`labels=0` 表示只显示选中点。

截图红圈对应交点：上 [114]、左 [316]、右 [136]、下 [345]。示例链接：
http://127.0.0.1:8765/index-lite.html?uvw=1,1,2&zoom=125&poles=1,1,4;3,1,6;1,3,6;3,4,5&labels=0

### 计算范围和依据

`pole-catalog.js` 展开 `model-drawings.js` 图例中的立方晶面族，以两晶面法向叉积生成互素晶向，再与模型多面体表面求交定位。每个结果验证 hu + kv + lw = 0。FCC 有 410 个有向交点，BCC 有 1658 个；包含正反方向，不表示有同样多种不等价晶向。没有采用任意点附近整数方向拟合来定义这些交点。

依据：https://dictionary.iucr.org/Zone_axis 和 https://dictionary.iucr.org/Weiss_zone_law 。

低指数简明版使用其实际声明的线族；原图版坐标层只覆盖这些线族，不能自动索引原图中的所有额外交点。交点指中心线交点，不是模拟的动力学强度峰。绘图舍入、纹理分辨率可造成像素级误差。

## 二维图纸下载
输入晶向并点击转到晶向，再点击生成当前晶向二维图纸。采用以该晶向为中心的球心投影，视野半角可选 15–60 度，支持 PDF、SVG、PNG，保留视野内选中的极坐标。图纸表示教学晶面族的中心线，不模拟带宽和强度。

## Si 200 kV 斑点叠加
二维预览中启用 Si 叠加，视场自动改为 ±2°；按金刚石结构筛选 ZOLZ 反射，|h|、|k|、|l|≤8，晶格常数取室温近似 0.5431 nm。电子相对论波长约 0.0025079 nm，斑点位置采用平面 ZOLZ / 弹性出射方向近似，不模拟强度、厚度、动力学禁反射或 HOLZ。晶面 400 与 200 法向一致，Si 模式将简明图中的该族标为 400。
选择下拉框中的斑点可查看 d、|g| 和散射角，PDF/SVG/PNG 共享同一绘图数据。
反射规则参考：https://www.jeol.com/words/emterms/20121023.044959.php
验证：node --test scripts/verify-silicon.cjs
