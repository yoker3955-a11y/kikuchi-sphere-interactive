# 任意晶向二维菊池带图

在两种图纸版本中，先输入 [uvw] 并转到晶向，再选择“生成当前晶向二维图纸”。二维窗口中可以直接更换晶向。

- 默认显示菊池带、中心线、晶面 (hkl) 标签及晶带轴 [uvw] 标签。
- 实线是几何布拉格边界；虚线是晶面中心线。带区填色用于识别，不表示强度或亮暗边。
- 默认 Si 金刚石结构、200 kV、a = 0.5431 nm。更换材料须填写实际立方晶格常数，选 FCC 或 BCC；一般 FCC 材料取消 Si 消光。BCC 默认数值不是材料标定值。
- ±35° 用于方向导航；±2° 或 ±5° 便于看清真实带宽。带宽没有人为放大。
- 查询框列出当前视场中的带、d 间距与几何带宽。部分密集标签为避免重叠会隐藏；全部可见带的指数保留在查询框和 SVG 元数据中。
- PDF/SVG 为矢量边界与可编辑文字；PNG 为位图。数值字段无效时取消旧图的导出链接。

## 数学模型

立方晶体 d(hkl) = a / sqrt(h²+k²+l²)。用相对论电子波长 λ 和 sin θB = λ/(2d) 定义带边界。

对于变换至屏幕坐标的单位法向 n，以及中心投影射线 s = (x,y,1)/sqrt(1+x²+y²)：

- 中心线：n·s = 0。
- 两条几何边界：n·s = ±sin θB。
- 法向截面角宽：2θB。投影后带边界一般为曲线，不使用全图等宽直线近似。

曲线用 512 段采样并裁剪，导出为矢量线段；填充使用闭合多边形。当前范围为 60–400 kV、a = 0.2–2 nm、半视场不超过 75°。同法向的反射采用当前线族内最低允许阶次。Si 中 {200} 改为 {400}，{420} 改为 {840}，保持方向关系并采用允许反射的带宽。有限的基础/扩展线族不是所有高指数反射的穷举。

Si 200 kV 的 (2 -2 0)：d ≈ 0.19201 nm，2θB ≈ 0.7484°。

该模型不计算动力学衍射强度、实际带边剖面、多重散射或厚度效应；实验强度极值位置不必与几何布拉格边界重合。
